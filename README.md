# dreamtui

Извлекает русскую озвучку Dream Cast с dreamerscast.com, автоматически синхронизирует её с вашим релизом (TorrServer или локальная папка с MKV) и собирает внешнюю дорожку `.mka` для IINA / mpv / VLC.

## Что делает

1. Разбирает страницу релиза Dream Cast и список серий.
2. Сопоставляет серии с видео: TorrServer `.m3u` или файлами в локальной папке. Номера серий берутся из имён файлов динамически.
3. Скачивает Opus-аудио через DASH (параллельно, с кэшем и resume); при недоступности — AAC HLS.
4. Обрабатывает несколько серий одновременно (по умолчанию 4): загрузка, синк и рендер каждой серии идут независимо.
5. Находит оригинальную (японскую) дорожку в видео и считает offset по side-сигналу (L−R) через нормализованную кросс-корреляцию.
6. Срезает вступление Dream Cast, при обнаружении пропуска в середине заполняет его оригинальной дорожкой.
7. Кодирует результат в Opus 192k `.mka` с тегами `language=rus`, `title=Dream Cast`.
8. По желанию (`--mux`) вшивает дорожку в локальный MKV без перекодирования видео.

При низкой уверенности синхронизации файл **не создаётся**: показывается отчёт, и нужно подтвердить offset вручную или применить результат принудительно.

## Сборка

```bash
go build -o dreamtui ./cmd/dreamtui
# или
make build
```

Требуются `ffmpeg` и `ffprobe` в `PATH`.

## TUI

```bash
./dreamtui
```

- Вставьте ссылку на релиз Dream Cast.
- Выберите источник: **TorrServer m3u** или **папка с MKV** (`←`/`→` на строке источника).
- Путь не подставляется сам — нажмите `Ctrl+F` и выберите файл/папку во встроенном проводнике. Путь можно и просто вставить.
- Проводник: `↑`/`↓` — выбор, `Enter` — открыть папку или выбрать файл, `Space` — выбрать текущую папку, `←`/`Backspace` — выше, буква — быстрый переход к имени, `Esc` — отмена.
- `Enter` — проверить релиз, затем выбрать серии и нажать `Enter` ещё раз.
- `Space` — выбрать/снять серию, `A` — все, `S` — авто-синк, `M` — mux, `F` — применять при низкой уверенности.
- Offset всегда подбирается автоматически по звуку; ручной ввод не нужен.
- До 4 серий обрабатываются одновременно: в экране запуска у каждой свой прогресс, а итоговый отчёт отсортирован по номерам.
- `Esc` — остановить/назад, `Ctrl+C` — выход.

## CLI

```bash
# локальная папка с сериями
./dreamtui extract \
  --video-dir "$HOME/Downloads/Cyberpunk Edgerunners 2 [2160p]" \
  "https://dreamerscast.com/home/release/629-cyberpunk-edgerunners-2"

# TorrServer m3u
./dreamtui extract \
  --m3u "$HOME/Downloads/Cyberpunk Edgerunners 2 [2160p].m3u" \
  "https://dreamerscast.com/home/release/629-cyberpunk-edgerunners-2"
```

Источник определяется по пути динамически: папка — локальные файлы, файл `.m3u` — TorrServer.

Полезные флаги:

| Флаг | Значение |
|---|---|
| `--m3u PATH` | TorrServer m3u (по умолчанию — свежий в `~/Downloads`) |
| `--video-dir DIR` | локальная папка с MKV/MP4 вместо TorrServer |
| `--out DIR` | папка вывода (по умолчанию рядом с источником: `<имя> - DreamCast`) |
| `--episodes 1,2` | только выбранные серии |
| `--limit N` | первые N серий |
| `--offset SEC` | ручной offset только для переопределения (`video_time - dub_time`); по умолчанию подбирается сам |
| `--no-sync` | не синхронизировать, взять дорожку как есть |
| `--apply-anyway` | применить синк даже при низкой уверенности |
| `--force` | перезаписать выходной файл и перекачать аудио |
| `--mux` | дополнительно собрать MKV с вшитой дорожкой (читает видео целиком и занимает место как исходник) |
| `--ref-index N` | индекс оригинальной дорожки в контейнере |
| `--parallel N` | сколько серий обрабатывать одновременно (по умолчанию 4) |
| `--workers N` | параллельных сегментов загрузки на серию (по умолчанию 8) |
| `--anchors N` | параллельных референсных окон (по умолчанию 4) |
| `--window SEC` | длина окна синхронизации (по умолчанию 30) |
| `--work-dir DIR` | папка кэша |
| `--dry-run` | показать план и выйти |

Имена выходных файлов повторяют имена видео из источника с суффиксом `.rus.mka`.
Рядом пишется `dreamtui-report.json` — offset, confidence, якоря, предупреждения.

## Как это работает

- **Аудио Dream Cast.** HLS-сегменты `_opus.mp4` на CDN сейчас отдают 404, поэтому Opus качается из DASH-манифеста (~166–172 фрагмента, ~37 МБ на серию). Если DASH недоступен, используется AAC HLS.
- **Синхронизация.** Из обеих дорожек считается RMS-огибающая side-сигнала (L−R) на 100 Гц. Центрированный диалог в ней подавлен, а музыка/эффекты сохраняются. Глобальный поиск идёт на 10 Гц, затем уточняется на 100 Гц. Окна — каждые 4 минуты по 30 секунд.
- **Offset.** Длительность и разница длительностей нигде не задаются вручную: offset считается кросс-корреляцией side-сигнала по якорям, разбросанным по всей серии. Разница длительностей используется только как подсказка при поиске и проверка результата.
- **Пропуски и края.** Пропуск в дубляже принимается только если он подтверждён несколькими соседними якорями и физически возможен: дубляж не может потерять больше, чем разница длительностей видео и дубляжа. Ложный пик корреляции, повторяющаяся музыка или совпавший фрагмент в другом месте серии не создают сдвиг. Найденный пропуск заполняется оригинальной дорожкой из видео. Если дубляж начинается позже видео или заканчивается раньше, недостающие края тоже заполняются оригиналом, а не тишиной.
- **Ограничения.** Для видео нужен доступ к TorrServer по HTTP (range/seek). Аудио и видео не перекодируются, кроме финального Opus-энкода дорожки.

## Проверка результата

```bash
ffprobe -v error \
  -show_entries format=duration:stream=codec_name,channels,sample_rate:stream_tags=language,title \
  -of default=nw=1 "Episode.rus.mka"
```

Ожидается `opus`, `48000`, `2 channels`, `language=rus`, `title=Dream Cast`, длительность примерно равна видео.

## Лицензия

Личный инструмент. Используйте только с контентом, к которому у вас есть доступ.
